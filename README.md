# Storage Space

Рабочий однопользовательский прототип файлового менеджера на Vue 3, FastAPI,
Python 3.14, SQLite, uv и Docker Compose. Зависимости backend заданы в
`backend/pyproject.toml` и закреплены в `backend/uv.lock`. Интерфейс использует
разметку, SVG-иконки и стили утверждённого прототипа. Сейчас подключено
хранилище «Тест»: каталог `storage/` внутри проекта на S4. Он создаётся
пустым и не попадает в Git. Это обычная папка на сервере, подключённая
в контейнер backend через bind mount. SSHFS-хранилища позже подключаются
тем же способом с режимом `sshfs`, для которого проверяется точка монтирования.
Backend работает с UID/GID `1000:1000`, владельцем тестового каталога на S4.
Операции приложения
идут через контракт `Storage` в `backend/storage.py`; сейчас реализован
адаптер `MountedStorage`. Позже можно добавить `SFTPStorage`, не меняя HTTP API
и Vue.

Загрузка идёт частями по 8 МиБ. Незавершённый файл лежит в скрытом каталоге
того же хранилища; сервер сообщает фактически записанное смещение. После
обрыва или перезагрузки страницы пользователь выбирает тот же файл, и передача
продолжается с сохранённого смещения. Скачивание и просмотр поддерживают HTTP
Range для возобновления и перемотки медиа. Браузер может потребовать повторно
выбрать файл после закрытия страницы. Загрузку можно отменить, чтобы удалить
незавершённый файл с хранилища.

## Запуск

```sh
docker compose up -d --build
```

Приложение слушает только `127.0.0.1:50007` на хосте. Изменить порт можно через
`APP_PORT` в `.env`. Страница открывается через Caddy по адресу
`https://storagespace.example`.

## Важно

Это пилотный интерфейс. В приложении пока нет входа пользователей и ACL.
Публичный доступ к нему должен быть закрыт на reverse proxy. Перед работой
с настоящими хранилищами также нужны проверка здоровья монтирования без
блокировки HTTP, защита от гонок при файловых операциях, очистка заброшенных
незавершённых загрузок и интеграционные испытания с обрывами SSHFS.

SFTP-клиент пока не реализован. В пилоте файлы отдаются через FastAPI;
перед эксплуатацией с большими файлами можно добавить прямую отдачу через
reverse proxy для SSHFS-адаптера.
